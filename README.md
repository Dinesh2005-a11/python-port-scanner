# Python Port Scanner

A Python-based port scanner that scans a target host and identifies open ports along with common network services.

## Features

- Scan custom port ranges
- Detect open ports
- Identify common services (SSH, HTTP, HTTPS)
- Display total open ports found
- Simple and beginner-friendly cybersecurity project

## Technologies Used

- Python
- Socket Programming

## How to Run

### 1. Clone the repository

```bash

git clone 
https://github.com/Dinesh2005-a11/python-port-scanner.git

```

### 2. Run the scanner

```bash

python scanner.py

```

### 3. Enter:

- Target IP / Hostname
- Start Port
- End Port

## Example Output

```text

Port 22 Open - SSH
Port 80 Open - HTTP
Port 443 Open - HTTPS

Scan Complete
Total Open Ports: 3

```
